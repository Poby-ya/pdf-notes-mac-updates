# PDF 필기

**PDF를 읽으면서 메모하고, 노트에 글과 그림을 함께 정리하는 도구입니다.**

읽는 자료와 필기 내용을 오가며 정리하는 작업을 돕기 위해 만든 개인 프로젝트입니다. 이 저장소는 Windows·Mac 배포 파일과 업데이트를 제공합니다.

**[사용 안내 보기 →](https://github.com/Poby-ya/pdf-notes-mac-updates/releases/latest/download/PDF-Notes-Guide-Windows.png)** · [Mac 사용 안내](https://github.com/Poby-ya/pdf-notes-mac-updates/releases/latest/download/PDF-Notes-Guide-Mac.png) · [최신 버전·다운로드](https://github.com/Poby-ya/pdf-notes-mac-updates/releases/latest)

## 어떤 기능을 만들었나요?

- **PDF 위 메모:** 글을 선택한 자리에서 메모를 작성합니다.
- **그림이 포함된 노트:** 캡처한 그림을 붙여넣거나 끌어 넣고, 크기와 자르기를 조절합니다.
- **정리한 내용 저장:** 노트의 글과 그림을 PDF에 함께 저장합니다.
- **읽기 화면 설정:** 공간·계절 테마와 어두운 화면을 선택합니다.

## 제가 맡은 역할

필기하면서 필요한 동작을 정하고 AI와 함께 구현한 뒤, 직접 사용·검증하며 개선했습니다. 메모를 만든 직후 바로 입력할 수 있게 고치는 등 작은 조작의 불편도 다듬었습니다.

배포 이후의 변경 내용과 버전 간 주의사항은 [릴리스 기록](https://github.com/Poby-ya/pdf-notes-mac-updates/releases)에서 확인할 수 있습니다.

프로젝트를 살펴볼 때는 위 사용 안내 이미지를 먼저 보시면 됩니다. 직접 사용할 때는 최신 릴리스에서 운영체제에 맞는 파일과 설치 안내를 확인하세요.
